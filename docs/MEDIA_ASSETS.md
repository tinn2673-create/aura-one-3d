# AURA ONE — MEDIA ASSETS & VISUAL SPECIFICATION

## 1. HỆ THỐNG QUẢN LÝ TÀI NGUYÊN HÌNH ẢNH
Tất cả hình ảnh và minh họa trong dự án được tổ chức đồng bộ theo tiêu chuẩn cao cấp:

1. **3D Real-time Visualizations:**
   * Mô hình 3D Three.js thủ tục (Procedural PBR) hiển thị trực tiếp trên Canvas WebGL tại 60 FPS, không phụ thuộc file tải ngoài nặng nề.
   * Bản đồ họa bề mặt Dynamic Canvas Texture 512x128px cho khắc laser thời gian thực.
2. **Photography & Studio Mockups:**
   * Phân loại: Product Photography (góc trước, góc nghiêng 45 độ, cận cảnh màng loa, khớp xoay Magie), Lifestyle Photography (studio làm việc, sáng tạo nội dung), và Technology Schematics (sóng âm, chip ANC).
   * Định dạng chuẩn hóa: SVG Vector siêu nét và WebP tối ưu dung lượng cao.
3. **Icons System:**
   * Lucide Icons vector đồng bộ nét viền 1.5px - 2px, màu Cyan / Purple / Titanium.
